# 동아리 알리미

동아리 **모임마다 한 일을 적고**, **다음 모임까지 해올 것을 나누고**, 부원들이 **미리 올리고 의견을 나누는** 곳입니다.
휴대폰에서 바로 쓰는 한 장짜리 웹사이트입니다.

**바로 쓰기 → https://junrepos.github.io/dongari/**

## 화면

| 탭 | 하는 일 |
| --- | --- |
| **오늘** | 다음 모임 D-day와 그날까지 해올 것, 내가 아직 안 올린 과제, 새 의견, 지난 모임 |
| **모임** | 회차·날짜·한 일·사진·참석한 부원. 다가오는 모임과 지난 모임으로 나뉩니다 |
| **준비물** | 해올 것마다 누가 했는지 한눈에. 부원은 동그라미를 눌러 ‘했어요’ 표시하고, 글·링크·사진을 올립니다 |
| **의견** | 하고 싶은 활동, 찾은 자료, 막힌 것을 올리고 댓글로 이어 갑니다 |
| **설정** | (선생님) 동아리 이름·모이는 때·소개, 참여 코드 만들기, 들어온 부원 보기·내보내기 |

## 누가 무엇을 할 수 있나요

- **선생님** — 계정으로 로그인. 모임 기록, 해올 것 올리기, 모든 글 고치고 지우기, 코드 관리
- **부원** — 선생님이 알려 준 **코드 여섯 자리**와 이름을 한 번만 넣으면, 그 기기에서 계속 쓸 수 있습니다.
  해온 것 올리기, 의견·댓글 쓰기, 자기 글 고치고 지우기
- **그냥 들어온 사람** — 동아리 소개와 모임 기록만 볼 수 있습니다

코드는 선생님 화면에서 언제든 새로 만들 수 있고, 이미 들어온 부원은 그대로 쓸 수 있습니다.
부원을 **내보내면** 그 기기에서 바로 글을 쓸 수 없게 됩니다.

## 처음 한 번 해야 하는 설정

이 사이트는 **반 사이트(2-6 알리미)와 같은 Firebase 프로젝트**를 씁니다. 저장 공간은 `club…` 으로 시작하는 곳만 따로 씁니다.

1. **Firestore 규칙** — 같은 프로젝트는 규칙 파일이 하나뿐입니다.
   [`schoollife/firestore.rules`](https://github.com/JunRepos/schoollife/blob/main/firestore.rules) 에 동아리 부분이 들어 있으니,
   그 파일 전체를 Firebase 콘솔 → Firestore → 규칙에 붙여 넣고 **게시**하세요. (`TEACHER_EMAIL` 자리에 선생님 이메일)
2. **Storage 규칙** — 마찬가지로 [`schoollife/storage.rules`](https://github.com/JunRepos/schoollife/blob/main/storage.rules) 를 올리면 동아리 사진(`club/`)이 열립니다.
3. **익명 로그인 켜기** — Firebase 콘솔 → Authentication → 로그인 방법 → **익명** 사용 설정.
   부원 기기에 권한을 붙이는 데 씁니다.
4. 사이트에 들어가 **선생님으로 로그인 → 설정**에서 동아리 이름을 적고 **코드를 만들어** 부원에게 알려 주세요.

규칙을 안 올리면 "규칙에 막혔습니다" 라는 빨간 글씨가 뜹니다.

## 저장되는 곳 (Firestore)

| 곳 | 무엇이 | 누가 봅니까 |
| --- | --- | --- |
| `clubInfo/main` | 동아리 이름·모이는 때·소개 | 누구나 |
| `clubJoin/code` | 참여 코드 | 선생님만 |
| `clubMembers/{기기}` | 부원 이름, 들어온 때 | 선생님과 부원 |
| `clubMeetings/{id}` | 모임 날짜·회차·한 일·사진·참석 | 누구나 |
| `clubTasks/{id}` | 해올 것, 기한, 누가 | 누구나 |
| `clubSubs/{과제__기기}` | 부원이 올린 것 | 선생님과 부원 |
| `clubIdeas` · `clubReplies` | 의견과 댓글 | 선생님과 부원 |

사진은 Storage `club/` 아래에 들어가고, 올리기 전에 긴 쪽 2000px로 줄입니다.
학생 이름 말고 학번·성적 같은 자료는 이 사이트에 담지 않습니다.

## 고치고 싶을 때

`index.html` 하나에 전부 들어 있습니다. 서버 없이 파일을 열어도 돌아가고,
`FIREBASE_CONFIG` 의 `apiKey` 를 비우면 **서버 없이 이 기기에만 저장하는 데모**로 바뀝니다(연습용으로 쓰기 좋습니다).

- 탭을 늘리려면 `TABS` 배열
- 색은 맨 위 `:root` 의 `--t-meet`, `--t-task`, `--t-idea`
- 글 서식(목록·굵게·표·링크)은 `renderRich()` 가 만들고, HTML 을 그대로 넣지 않아 안전합니다
